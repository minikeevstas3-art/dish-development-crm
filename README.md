# CRM блюд в разработке

Простое браузерное приложение на HTML, CSS и JavaScript.

## Что умеет

- показывает 10 нейтральных блюд в разработке;
- дает два рабочих режима: доска по статусам и компактный список;
- показывает фокус дня: что сейчас важнее всего довести;
- хранит статус, следующий шаг, ответственного, срок, проблему и правки;
- дает карточку блюда с комментариями от Станислава и Эльдара;
- умеет быстро отмечать блюдо как готовое или возвращать в проработку;
- фильтрует по статусу, ответственному и поиску;
- умеет быстро показывать только зависшие или только готовые блюда;
- сохраняет изменения в браузере;
- экспортирует и импортирует данные через JSON-файл.

## Как открыть локально

Открой файл `index.html` в браузере.

## Ограничения

Без backend, базы данных и логина данные сохраняются только в браузере конкретного устройства. Для обмена между устройствами используй экспорт и импорт JSON-файла.
